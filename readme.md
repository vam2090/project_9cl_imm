# Прототип 

## Структура проекта

- config.txt - файл, где задаются координаты начальной и конечной точек движения для иммитаци маршрута, по которому движется СИМ, и координаты вершин велодоржки.
- bike_path - файл, где задаются координаты вершин велодоржки в десятичном формате. Координаты вершин разделяются пробелами, долгота и широта одной вершины - запятыми.
- immit_data.txt - файл, в который записываются сымитированные координаты движения по маршруту.
- immit.py - программа для генерации сымитированных координат движения по маршруту.
- imm_impl.py - главный программный модуль прототипа.

## Запуск прототипа

Для иммитации исходных данных:

1. Введите исходные данные в config.txt
2. Введите команду в комадной строке в корне проекта:

    ```python
    python3 ./immit.py
    ```


Для запуска прототипа введите команду в комадной строке в корне проекта: 

```python
python3 ./imm_impl.py
```
